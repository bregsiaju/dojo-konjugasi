# Dojo Konjugasi

Website latihan konjugasi kata kerja dan kata sifat bahasa Jepang (JLPT N5–N3).

- Jawaban diketik dalam kana (romaji otomatis diubah jadi kana).
- Penjelasan aturan dan pengecualian setiap kali menjawab.
- Pengulangan berjarak: yang salah muncul lagi lebih cepat.
- Mode Tebak Bentuk, Tabel konjugasi, dan Statistik per bentuk.

Semua ada di `index.html` (tanpa build step). Progres disimpan di `localStorage` browser.

## Menjalankan lokal

Buka `index.html` langsung di browser.

## Deploy

Netlify membaca `netlify.toml` dan menerbitkan folder root apa adanya (tanpa perintah build).
